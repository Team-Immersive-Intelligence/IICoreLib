Team Immersive Intelligence Mk. X Build System
-------------------------

Common tasks:
  ./gradlew runClient
  ./gradlew runServer
  ./gradlew runObfClient
  ./gradlew runObfServer
  ./gradlew build
  ./gradlew test
  ./gradlew spotlessApply

Project identity lives in gradle.properties:
  mod_id, mod_name, mod_group, mod_package, mod_version

Important build switches:
  ii_script_repositories   enable Team II / GTNH / Cleanroom / mod Maven repositories
  ii_script_ide            generate IntelliJ IDEA settings and Gradle run configurations
  ii_script_lombok         enable Lombok compileOnly and annotationProcessor dependencies
  ii_script_modworks       enable Team II Modworks processor and generated folders
  ii_script_junit          enable JUnit 5, MinecraftJUnit and JMeasure
  ii_script_spotless       enable Spotless formatting tasks
  ii_script_dependencies   enable Immersive Engineering addon dependencies
  ii_script_corejar        build and embed a separate reobfuscated core jar
  ii_script_signing        sign reobfuscated jars using Ant signjar

Modern Java syntax:
  ii_use_modern_java_syntax=true enables Jabel and compiles modern Java syntax to Java 8 bytecode.
  Keep this disabled unless the whole team uses a compatible Gradle/RFG toolchain.

Signing:
  Set ii_script_signing=true, then provide either Gradle properties
  or environment variables: SIGN_ALIAS, SIGN_KEYSTORE, SIGN_STOREPASS, SIGN_KEYPASS, SIGN_TIMESTAMP.
  You can implement a method receiving a FMLFingerprintViolationEvent via @Mod.EventHandler in your mod class to handle this exception.
  The fingerprint should, but may not be present when running the client in the IDE due to how IntelliJ makes shortcuts through Gradle's build system.
